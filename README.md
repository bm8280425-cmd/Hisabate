# حساباتي V3
مشروع Android Studio لتطبيق محاسبي عربي يعمل محليًا.

## الوظائف
- SQLite محلي دائم.
- سند قبض وصرف مع ترقيم تلقائي.
- رصيد افتتاحي وحساب الرصيد الحالي.
- سجل السندات وحذف السند.
- تقارير أساسية.
- إعدادات اسم المنشأة والعملة والرصيد الافتتاحي.
- تصدير نسخة احتياطية CSV.
- يعمل دون إنترنت.

## البناء
افتح المشروع في Android Studio، نفّذ Gradle Sync ثم Build > Build APK(s).

ملاحظة: هذه البيئة لا تحتوي Android SDK/Gradle، لذلك تم تسليم مشروع المصدر وليس APK مبنيًا.
